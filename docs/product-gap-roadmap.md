- 分类

- 首页

- 排期/榜单
- 我的

搜索始终位于首页和分类页顶部。

### 2.2 首页模块

1. 轮播推荐
2. 今日更新
3. 正在热播
4. 日漫 TV

6. 国漫

每个模块必须来自统一目录 API，不能只依靠某一个来源首页的分区名称。

### 2.3 分类体系

统一筛选维度：

- 内容形态：TV、剧场版、OVA/OAD、短篇、真人影视。
- 地区：日本、中国、欧美、韩国、其他。
- 题材：冒险、奇幻、校园、恋爱、喜剧、悬疑、科幻、运动、音乐、治愈等。

- 评分：9+、8+、7+、全部。
- 排序：热度、评分、更新时间、首播时间。

来源方原始分类先映射到聚映规范标签，无法映射的保留 `rawTags`，不能静默丢弃。

## 4. 多源适配计划

### 4.1 Native Adapter

目标来源：

- Lanerc
- AuvFun
- Cycapp
- Jinpai
- Sanqiu

任务：

1. 为每个 Adapter 建立固定响应 Fixture。
2. 完成首页、搜索、详情、播放四项契约测试。
3. 区分“Adapter 已编写”“已配置”“健康”“播放已验证”四种状态。
4. 将来源专用认证全部封装在 Adapter 内。
5. 输出规范化类型、分类标签、剧集号、质量信息和过期时间。

### 4.2 JS Worker

目标来源：

- 瓜子
- 双星
- 云帆
- 咕咕动漫

要求：

- 独立进程/隔离 Worker。
- 固定允许的宿主 API，不提供任意文件系统和进程能力。
- 网络访问按来源 Manifest 控制。
- CPU、内存、总耗时、响应大小均有限制。
- 远程脚本先下载、校验、版本化和人工审核，再进入运行环境。
- 主 API 只接收规范化 JSON，不接收可执行代码。

### 4.3 Browser Worker

目标来源：

- 稀饭动漫
- AkiAnime
- 动漫在线
- 动漫巴士

要求：

- 独立浏览器池，不与用户浏览器会话共享。
- 域名级并发限制。
- 页面加载、脚本执行和选择器全部有超时。
- 禁止持久 Cookie，除非来源明确授权且有专用凭据。
- DOM 解析结果必须进入同一 Adapter 合约。
- CAPTCHA、登录墙和付费内容不自动绕过。

## 5. 播放器完善规格

### 5.1 控制层

竖屏与横屏都需要：

- 播放/暂停
- 当前时间/总时长
- 可拖动进度条
- 上一集/下一集
- 选集
- 换源
- 清晰度
- 倍速
- 弹幕开关
- 弹幕设置
- 画中画
- 全屏
- 锁定控制
- 更多菜单

移动端横屏额外支持：

- 左侧上下滑调亮度
- 右侧上下滑调音量
- 横向滑动调进度
- 双击左/右区域快退/快进
- 控件自动隐藏

### 5.2 播放状态机

建议状态：

```text
idle
  -> resolving
  -> loading
  -> playing / paused
  -> ended
  -> auto_next

resolving / loading / playing
  -> recoverable_error
  -> switching_source
  -> loading

recoverable_error
  -> fatal_error
```

状态必须记录：

- 当前作品、集号和来源。
- 当前播放时间和时长。
- 当前清晰度和倍速。
- 来源候选列表。
- 是否全屏、画中画、锁屏。
- 弹幕开关和设置。
- 自动下一集倒计时。

### 5.3 下一集

下一集不能只依赖按钮顺序，应使用规范集号：

1. 当前集播放结束。
2. 保存完成状态。
3. 查找 `episodeNumber + 1`。
4. 优先使用当前健康来源。
5. 当前来源无下一集时匹配其他来源。
6. 显示 5 秒倒计时，允许取消。

### 5.4 换源

换源面板展示：

- 来源名称
- 路线名称
- 最近成功率
- 最近解析耗时
- 清晰度能力
- 当前选中状态

自动换源只在网络错误、解析失败或媒体不可播放时触发，不能在用户明确选择来源后无提示切换。

### 5.5 倍速

固定选项：

- 0.5x
- 0.75x
- 1.0x
- 1.25x
- 1.5x
- 2.0x
- 3.0x

偏好保存在设备端，切集时保留。

### 5.6 画中画

- 使用 `document.pictureInPictureEnabled` 和媒体元素能力检测。
- 不支持时隐藏或禁用，并显示原因。
- iOS 使用系统允许的 `playsInline`/原生能力，不伪造入口。

### 5.7 弹幕

弹幕必须有明确的数据来源，不能把评论伪装成弹幕。

目标接口：

- `GET /api/danmaku?mediaId=&episode=`
- `POST /api/danmaku`

设置项：

- 开关
- 透明度
- 字号
- 速度
- 显示区域
- 顶部/底部/滚动类型
- 同屏密度
- 关键词屏蔽
- 用户屏蔽
- 彩色弹幕开关

若没有授权弹幕来源，播放器应显示“暂无弹幕通道”，但设置面板和本地测试通道可以独立开发。

### 5.8 缓存

缓存分为两类：

- 元数据缓存：服务端允许，当前已有基础实现。
- 视频离线缓存：只能在用户设备进行，且来源明确允许、CORS/DRM/协议支持时启用。

服务端仍不保存影片。缓存页需要显示任务、大小、进度、清晰度、失败原因、删除和空间占用。

## 7. 榜单与排期

### 7.1 热度榜

不能直接混用不同来源的“热度”字段。建议统一分数：

```text
heatScore =
  0.35 * normalizedSourceHeat +
  0.25 * recentDetailViews +
  0.20 * recentPlayStarts +
  0.10 * favorites +
  0.10 * freshness
```

匿名统计必须聚合、限时保存并提供隐私说明。第一阶段也可以只使用来源方公开榜单，并标记来源。

### 7.2 番剧排期

模型：

- 星期
- 预计更新时间
- 时区
- 作品 ID
- 下一集号
- 来源更新时间
- 是否已更新

展示：

- 周一到周日标签。
- “今天”默认选中。
- 已更新、待更新、时间未知三种状态。
- 支持按地区和内容形态筛选。
