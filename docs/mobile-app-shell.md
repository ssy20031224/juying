# 移动端 App 外壳

当前项目的移动端采用响应式 Web + PWA 外壳，手机浏览器访问网站后可以“添加到主屏幕”，得到独立窗口、启动图标和底部导航体验。它和原生 App 共用同一套 API、适配器和播放页，不会因为重复维护一套业务逻辑而产生数据差异。

## 已完成

- `public/manifest.webmanifest`：应用名称、启动地址、主题色和图标。
- `public/sw.js`：仅缓存同源脚本/样式和页面壳；不缓存 `/api/*`、跨域封面、视频或播放地址。
- 移动端布局：搜索、精选轮播、横向内容行、片库、详情选集、播放器、收藏/历史和底部导航。
- 收藏与历史使用设备本地存储，不上传用户观看记录。

## 发布方式

1. 网站部署到 HTTPS 域名。
2. Android Chrome 打开网站，选择“添加到主屏幕”即可安装 PWA。
3. 如果需要上架应用商店，可以用 Trusted Web Activity 或 Capacitor 包装同一域名；原生层只负责启动窗口、状态栏和系统返回键，检索/播放仍走本项目后端。

## 原生层边界

原生播放器可以在后续版本替换当前 HTML5 `<video>`，但必须继续遵守：播放 URL 只在请求时短暂返回，元数据可以缓存，视频字节不经过本服务端落盘。清晰度按钮由适配器返回的 `qualityOptions` 驱动，某个来源不提供多码率时显示 `AUTO`，不伪造清晰度。
